# SecureScope v5.3.8.12 — Assurance Merge, Full Functionality

## Rule

The Control Assurance merge is a navigation consolidation only. Existing mature
registers, tables, forms, buttons and service calls must remain available.

## Control Assurance navigation

- Control profiles — complete control register and metrics.
- Assess control — full manual/assisted assessment workflow.
- Evidence — the complete Evidence Hub workflow embedded in the assurance page.
- Gap actions — persistent gap register plus improvement action / POA&M workflow.
- Statement of Applicability — working editor, version history and snapshot approval.
- Risk Treatment Plan — existing plan register and creation workflow.

## Evidence workflow retained

The embedded Evidence area keeps the original:

- Overview
- Tool Catalog
- Collect Evidence
- Import Reports
- Manual Evidence
- Consultant Review
- Evidence Requests
- Auditor Package

No evidence feature is replaced by a reduced dashboard-only view.

## Product principle

Merge duplicated navigation, not business capability. A user should have fewer
places to go without losing the tables and actions they already rely on.
