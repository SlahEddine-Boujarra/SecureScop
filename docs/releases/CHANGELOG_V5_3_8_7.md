# SecureScope v5.3.8.7 — Programme Interaction System

## UX hierarchy

- Programme Overview now has one primary next action: Continue discovery.
- Discovery shows one preparation task at a time instead of three simultaneous tab workspaces.
- Context and Interested Parties use recommendation-first flows with manual entry as a secondary path.
- Scope preparation, controlled editing, and human approval are visually separated.
- Roles & RACI prioritizes formal ISMS responsibility assignment before engagement-team administration.
- Creating another engagement is moved into an administration expander; milestones are the active-cycle primary task.

## Batch review

- Context recommendations can be selected and added in one reviewed batch.
- Interested parties and starter requirements can be selected and added in one reviewed batch.
- Per-card Add buttons were removed to reduce visual noise and repeated clicks.

## Register system

- Added reusable register headings.
- Register tables normalize ambiguous empty values and booleans.
- Programme tables were reordered to put business identity first.
- Large registers were reduced toward 5–7 default columns.
- Empty-state language now points to the preferred workflow instead of always suggesting manual creation.

## Architecture

No scanner, evidence, control-assessment, migration, SoA, risk-treatment, remediation, or reporting logic was removed. This release changes the Programme Setup interaction layer only.
